# Codex and MCP Transition History

This directory preserves selected evidence supporting the DocPilot Core delivery operating model. Historical reports describe the state at their execution time and are not silently rewritten to match later conclusions.

Current policy is defined by the [MCP-governed Codex RFC development methodology](../../development/MCP-GOVERNED-CODEX-RFC-DEVELOPMENT-METHODOLOGY.md):

- MCP is `MAINTENANCE_ONLY` and temporarily retained for governance.
- Codex performs Core analysis, detailed planning, implementation, tests, and correction.
- People and Main Planning retain product, approval, integration, and release authority.
- Repository documents are the source of truth.
- Direct Codex-only transition is not approved.
