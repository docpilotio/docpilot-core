# RFC-0060 Starting Prompt

Begin from RFC-0059 DIR 0.4 and Snapshot format 2. Define an Evidence-bounded,
deterministic projection into Feature, Entry Point, Scenario, and ordered Step
entities. Do not infer missing owners, flows, or ambiguous targets; emit explicit
UnresolvedItems. Decide when `DefaultSpecificationBuilder` may move from DIR 0.3
to 0.4 and specify compatibility tests first.

Keep RFC-0052 artifact contracts, Evolution Report format 1, Profile identity
and hashes, public-v1, PV-009, and RC status unchanged unless separately
approved. Feature Markdown rendering remains out of scope until explicitly
authorized.
