# RFC-0068 Completion Handoff

`docpilot generate docs` now supports preview-first full/selective deterministic generation, exact Profile identity, canonical Plan SHA-256, safe output checks, ownership protection, Snapshot-last apply, text/JSON output, and stable status-to-exit-code mapping. Existing `generate specification` remains available.

RFC-0069 should consume the structured generation result to implement Documentation Bundle and Manifest. Product Validation and PV-009 are unchanged.
