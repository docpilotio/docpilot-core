# DEC-0001 — Project Direction

Status: Accepted  
Priority: Critical

## Decision

DocPilot is an AI-native Specification Engineering Framework, not a simple documentation generator.

## Context

The project must represent architecture, behavior, relationships, lifecycle, state, APIs, callbacks, and evidence—not only class or function lists.

## Consequences

- Specification is treated as the core product asset.
- Documentation becomes a rendered output.
- Analyzer, domain model, evidence, and renderer concerns remain separated.
