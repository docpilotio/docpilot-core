# DEC-0005 — Primary User

Status: Accepted  
Priority: High

## Decision

The primary user for the initial product is the Android developer.

## Initial Scope

- Android projects
- Kotlin
- Gradle
- Android Studio workflows

## Consequences

- Product usability and examples should prioritize Android development.
- Other platforms are deferred.
- Core remains reusable, but implementation priorities follow Android developer needs.
