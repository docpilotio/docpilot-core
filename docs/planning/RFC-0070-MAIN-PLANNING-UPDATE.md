# RFC-0070 Main Planning Update

RFC-0070 completed the RFC-0069 prerequisites, then added bounded Section-level AI enrichment without changing DIR 0.5, Snapshot authority, extraction, relationships, evidence, or unresolved decisions.

Delivered layers:

1. Core enrichment contracts, canonical prompt identity, validation, managed section insertion, caching, and stale-by-identity behavior.
2. Explicit CLI provider/model/target selection with fixture, Ollama, and OpenAI SPI compatibility.
3. additive Bundle/Manifest/Receipt provenance and enrichment aggregate hashing.
4. offline verification, selective full-index preservation, failure fallback, and `NO_CHANGES` reuse.

Diagram IR, Mermaid rendering, Claims/Traceability, quality gates, Product Validation re-entry, and automatic provider fallback remain out of scope. The next RFC is RFC-0071 — Diagram IR and Mermaid Rendering.
